# One data folder — Phase 4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move every reader, solver and snapshot fixture out of `tests/**/fixtures/` into `data/` with a `source.yaml` each, regenerating what has a generator, so that after phase 3b nothing is left under any `tests/**/fixtures/`.

**Architecture:** A layout test lists the tracked files under any `tests/**/fixtures/` and fails on everything outside a shrinking allowance. Each task moves one family, removes it from the allowance, and rewrites its consumers. Files with a generator (GAMS `.gms`, an equilibria script) are regenerated, diffed against the committed file, and recorded with `write_source.py`; files without one are recorded as `--kind data --no-run` with the commit they came from.

**Tech Stack:** Python ≥3.10, pytest, `uv`, GAMS 53 (`/Library/Frameworks/GAMS.framework/Versions/53/Resources` on `PATH`), `gdxdump`, `scripts/dev/write_source.py`, `equilibria.sources`.

**Spec:** `specs/data/changes/one-data-folder/design.md` (phase 4 in "Phases"; "When a regenerated file differs from the old one"), `docs/adr/0010-one-data-folder.md`.

## Global Constraints

- No number changes (ADR-0008): a test that reads a moved file keeps its assertions. `git mv` when the bytes are kept.
- A regenerated file is diffed against the one it replaces before the old one goes. A GDX is compared by `gdxdump` content, not bytes (its header carries the GAMS version and time). Any difference stops the task for that file and goes in the PR.
- Generators live with the data (`data/<area>/tools/`), and every result folder records its generator in `source.yaml`.
- Names in English. The Spanish names in `SPANISH_LEGACY` that this phase moves are renamed, and their entries are removed from `scripts/dev/check_layout.py`.
- Suite before and after identical by test name **and skip reason** (baseline: main `4e91d12a`), except tests this phase adds. `scripts/gtap/run_parity_gates.py` gives identical stamped figures.
- Commits in English, `type(scope): description`, with the session's `Co-Authored-By` line.

## Review Focus

1. A GDX regenerated by GAMS 53 that differs in content from the committed one: stop and explain (version, set order, compression), never overwrite. Task 1 diffs every file.
2. A `.gms` whose output name does not match any committed GDX (the `grep` found no `execute_unload` in 7 of 9): Task 1 runs each one in a scratch folder and maps its actual outputs before moving anything.
3. A consumer outside `tests/` still pointing at `tests/fixtures` (40 scripts in `examples/gdx/`, `docs/site/examples_src/example_mip_to_sam.py`, `scripts/gtap/*_fixture.py`, `check_parity_gates_stamp.py`): Task 6 adds a `git grep` test that fails on any.
4. A test that silently turns into a skip because its path no longer exists (`test_reader.py:300` has `skipif(not ...exists())`): the suite diff compares skip reasons, not only names.
5. An equilibria snapshot regenerated on today's main that differs from the committed one: that means main moved since the snapshot; record the commit it was taken at and stop, do not re-baseline silently.

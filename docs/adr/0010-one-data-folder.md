# One `data/` folder, and every reference file says where it came from

Everything that is not equilibria code lives in one folder, `data/`, at the
root of the repository: the input datasets, the reference models that produce
results (the GAMS `.gms` files), the results of those reference models (GAMS
`.nl` and GDX, GEMPACK HAR and SL4) and the small files the readers are tested
with. Inside `data/`, one dataset is one folder, and each result sits next to
the data it was computed from. `src/` holds code only; `tests/` holds tests
only.

Every folder of reference results carries a `source.yaml` that says how it was
produced: which dataset, which reference model, which variant (`ifSUB`,
closure, phase), which tool and version, which command, and the sha256 of the
inputs. A test reads those files: a result without one, a result whose
inputs changed after it was generated, or a result requested with a different
variant than the one it records, is red.

Before this, reference files lived in seven places, sorted by dataset in some,
by tool in others and by experiment in a third (`tests/fixtures/` and its root,
`tests/fixtures/gtap7_gempack/`, `src/equilibria/templates/reference/`,
`datasets/`, `runs/`, `output/`, `results/`). The same nus333 data was
committed twice, byte for byte. Nothing recorded how a file was made, and three
times a test trusted a reference that was not what it was believed to be:

- a `.gms` fixture that did not correspond to its GDX (a published 52 % that
  was false),
- a comparator built with the default closure instead of the experiment's
  (nus333, 56 %),
- the `.nl` gate (#23) building Python with `ifSUB=0` against GAMS fixtures
  that lack exactly the nine families `ifSUB=1` substitutes (`pm`, `pefob`,
  `pmcif`, `pwmg`, `xwmg`, `xmgm`, `pfa`, `pfy`, `pp`), measured 2026-10-28.

In each case the test stayed green, because a test can only be as right as
the file it reads.

## Consequences

- A test asks for a reference by what it is (dataset, tool, variant), not by a
  path; the helper checks the request against `source.yaml`. A variant
  mismatch is an error, not a silent comparison.
- No reference of unknown origin survives the change: every result is
  regenerated by its recorded command and diffed against the file it replaces;
  a difference is explained before the old file goes.
- The datasets that ship with the package (`nus333`, `9x10`) are copied into
  the wheel from `data/` at build time; there is no second copy in `src/`.
- Moving a file is not a reason to change a number: every move keeps the test
  suite and the parity gates exactly as they were (ADR-0008).

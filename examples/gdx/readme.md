# gdx examples

Examples for the GDX module. They read the reader-test specimens in
`data/gdx_tests/specimens/` (ADR-0010).

- Reading and writing: `gdx_reader_example.py`, `gdx_reader_vars_eqs.py`, `gdx_writer_demo.py`, `gdx_set_reader_demo.py`, `gdx_full_demo.py`
- Multidimensional: `multidim_examples.py`, `example_5d_usage.py`, `example_6d_usage.py`
- Interpolation and sequences: `gdx_interpolation_issue.py`, `gdx_sequence_detector.py`

Quick start:

```bash
uv run python examples/gdx/multidim_examples.py
uv run python examples/gdx/example_6d_usage.py
```
